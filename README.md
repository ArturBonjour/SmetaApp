## 🎯 О продукте

СметаАпп — веб-приложение для строительных компаний, которое заменяет Excel-таблицы на интерактивный 2D-конструктор. Пользователь рисует план здания (баня, дом, гараж), а система автоматически рассчитывает смету в реальном времени.

## ✨ Ключевые возможности

| Возможность | Описание |
|---|---|
| 🏗 **2D-конструктор** | Рисуй стены, полы, кровлю, окна и двери |
| ⚡ **Автосмета** | Стоимость пересчитывается при каждом изменении |
| 📦 **Каталог материалов** | 30+ позиций с реальными ценами + импорт/экспорт CSV |
| 📐 **Шаблоны проектов** | Баня 5×3, Дом 6×8, Гараж 6×4, Дом 8×10 |
| 📊 **Экспорт PDF / Excel** | Профессиональная смета за один клик |
| 🔢 **Наценки и скидки** | Настраиваемые коэффициенты к итоговой сумме |
| ↩ **Undo / Redo** | Неограниченная история действий |
| 💾 **Автосохранение** | Каждые 2 секунды, + версионирование |
| 🌙 **Тёмная тема** | Полная поддержка dark mode |
| ⌨ **Горячие клавиши** | Ctrl+K, Ctrl+N, Ctrl+S, F (fit), ? (помощь) |
| 🔔 **Лента активности** | Все изменения в реальном времени |

## 🛠 Технологии

**Frontend**: React 18 + TypeScript + Vite + Konva.js + Zustand + Tailwind v4 + Framer Motion + Recharts  
**Backend**: Node.js 20 + Express + TypeScript + Prisma 5 + SQLite  
**Export**: ExcelJS + jsPDF  
**Инфра**: Docker + Nginx

## 🐳 Быстрый старт через Docker (рекомендуется)

### Требования
- Docker 20.10+
- Docker Compose v2+

### 1. Клонирование и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ArturBonjour/SmetaApp.git
cd SmetaApp

# 2. (Опционально) Задать свой JWT_SECRET
export JWT_SECRET="ваш-секретный-ключ"

# 3. Собрать и запустить все сервисы
docker compose up --build
```

> Первый запуск займёт ~2–3 минуты (сборка образов).  
> Повторный запуск: `docker compose up -d` (несколько секунд).

### 2. Открыть приложение

| Сервис | URL |
|---|---|
| 🌐 Приложение | http://localhost |
| 🔌 API / Health | http://localhost:3001/health |

### 3. Демо-вход

На странице входа нажмите **«Войти в демо-режиме»** или введите:
- Email: `demo@smeta.app`  
- Пароль: `demo123`

## 🖥 Локальная разработка (без Docker)

### Требования
- Node.js 18+
- npm 9+

### Установка

```bash
# 1. Клонировать
git clone https://github.com/ArturBonjour/SmetaApp.git
cd SmetaApp

# 2. Установить зависимости, создать и засидить БД
npm run setup

# 3. Запустить в режиме разработки
npm run dev
```

После запуска:
- **Фронтенд**: http://localhost:5173  
- **Бэкенд**: http://localhost:3001

## 🗺 Маршрут тестирования

Следуй по этому пути чтобы проверить все функции приложения:

### Шаг 1 — Вход
1. Открой http://localhost (Docker) или http://localhost:5173 (dev)
2. Нажми **«Войти в демо-режиме»**
3. ✅ Ожидание: перенаправление на страницу проектов

### Шаг 2 — Дашборд проектов
1. Убедись, что видны карточки с статистикой (Всего / Активных / Завершённых / Сумма)
2. Нажми **«Новый проект»** (или `Ctrl+N`)
3. Выбери шаблон **«Дом 6×8»**, введи название `Тестовый дом`, установи теги `жилой`, бюджет `500000`
4. Нажми **«Создать»**
5. ✅ Ожидание: проект появился в списке с превью и тегом

### Шаг 3 — Редактор плана
1. Кликни на карточку проекта
2. ✅ Ожидание: открылся 2D-редактор со стенами шаблона на канвасе
3. Выбери инструмент **«Стена»** (клавиша `W`)
4. Нарисуй дополнительную стену — кликни на канвасе, потяни, кликни снова для завершения
5. Нажми `Ctrl+Z` — стена исчезла (Undo)
6. Нажми `Ctrl+Y` — стена вернулась (Redo)
7. Выбери инструмент **«Пол»** (`F` в меню инструментов), нарисуй область
8. Нажми `Ctrl+S` или кнопку **«Сохранить»**
9. ✅ Ожидание: тост «Сохранено», правая панель «Смета» обновилась с новыми суммами

### Шаг 4 — Смета
1. В правой панели проверь: числа по категориям (Стены, Полы и т.д.)
2. Установи наценку `10` → нажми **«Применить»**
3. ✅ Ожидание: итог вырос на 10%
4. Нажми иконку **Excel** (зелёная) → скачался `.xlsx` файл
5. Нажми иконку **PDF** (красная) → скачался `.pdf` файл

### Шаг 5 — Каталог материалов
1. В навигации нажми **«Каталог»**
2. ✅ Ожидание: 30+ системных позиций с ценами
3. Нажми **«Добавить позицию»** → заполни форму → сохрани
4. ✅ Ожидание: новая позиция в списке с тегом «Пользовательская»
5. Нажми кнопку **CSV** (Download) → скачался файл `catalog_export.csv`
6. Нажми **CSV** (Upload) → выбери тот же файл → позиции дублировались (или обновились)

### Шаг 6 — Command Palette
1. Нажми `Ctrl+K`
2. ✅ Ожидание: открылась палитра с поиском
3. Введи название своего проекта — он появился в результатах
4. Нажми `Escape` — палитра закрылась

### Шаг 7 — Тёмная тема
1. Нажми иконку 🌙 в шапке
2. ✅ Ожидание: весь интерфейс переключился в тёмный режим
3. Переключи обратно в светлый

### Шаг 8 — Уведомления
1. Нажми иконку 🔔 в шапке
2. ✅ Ожидание: дропдаун с последними событиями (создание проекта, сохранение)

### Шаг 9 — Версионирование
1. Вернись в редактор своего проекта
2. Нажми стрелку ▼ рядом со «Сохранить» → выбери **«Новая версия»**
3. ✅ Ожидание: создана версия v2, переключение между версиями доступно

## 🔌 API Reference

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/login` | Вход по email/паролю |
| POST | `/api/auth/register` | Регистрация + создание организации |
| POST | `/api/auth/demo` | Одноклик демо-вход |
| GET | `/api/projects` | Список проектов организации |
| POST | `/api/projects` | Создать проект |
| GET | `/api/projects/search?q=` | Полнотекстовый поиск |
| GET | `/api/projects/stats` | Статистика (count, sum) |
| GET | `/api/projects/:id` | Проект + версии |
| PATCH | `/api/projects/:id` | Обновить метаданные |
| DELETE | `/api/projects/:id` | Удалить |
| POST | `/api/projects/:id/duplicate` | Дублировать |
| PUT | `/api/projects/:id/geometry` | Сохранить план + пересчитать смету |
| GET | `/api/projects/:id/versions` | История версий |
| POST | `/api/projects/:id/versions/:v/restore` | Восстановить версию |
| GET | `/api/catalog` | Каталог материалов |
| POST | `/api/catalog` | Добавить позицию |
| PUT | `/api/catalog/:id` | Изменить позицию |
| DELETE | `/api/catalog/:id` | Удалить позицию |
| GET | `/api/estimation/:projectId` | Получить смету |
| PUT | `/api/estimation/:projectId/adjust` | Наценка/скидка/заметки |
| GET | `/api/estimation/:projectId/export/excel` | Скачать Excel (.xlsx) |
| GET | `/api/estimation/:projectId/export/pdf` | Скачать PDF |
| GET | `/api/activity` | Лента активности |

## 🐛 Известные ограничения

- SQLite не подходит для высоких нагрузок — для production рекомендуется PostgreSQL (миграция через Prisma тривиальна)
- Совместная работа в реальном времени (WebSocket) — в разработке
- Мобильная версия — частичная поддержка (редактор оптимизирован для десктопа)
