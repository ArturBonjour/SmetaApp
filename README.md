# SmetaApp
ТЕХНИЧЕСКОЕ ЗАДАНИЕ (КРАТКО)

ЦЕЛЬ
Создать визуальный инструмент (как в Sims), где пользователь “рисует” объект (баня/дом), а система автоматически считает смету.

СУТЬ
Пользователь задаёт размеры → добавляет элементы → получает стоимость в реальном времени.

ФУНКЦИОНАЛ
- Простой 2D/упрощённый 3D редактор
- Перетаскивание элементов:
  стены, полы, крыша, окна, двери, инженерия
- Библиотека материалов с ценами
- Авторасчёт:
  площади, объёмы, итоговая стоимость
- Выгрузка сметы (таблица)

ЛОГИКА
Каждый элемент имеет:
- единицу измерения (м² / м.п. / шт)
- цену

При добавлении элемента → автоматический пересчёт общей стоимости

ИНТЕРФЕЙС
Простой, как игра: “нарисовал → получил цену”

ФОРМАТ
Web или Desktop, без тяжёлой графики (быстрый прототип)

РЕЗУЛЬТАТ
Прототип, где можно собрать баню (например 5×3) и получить смету

ЗАДАЧА ДЛЯ ОЦЕНКИ
- Реализуемость
- Сроки
- Стоимость разработки
